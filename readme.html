Project Information

CarX is an autonomous rover that roams around rooms, mapping the Wi-Fi signal strengths as a height map, and pinpointing the source of the Wi-Fi signals.

It uses several components to perform its task, namely:

  • ESP32 - The main board of the project
  • LM2596 - The power supply regulator (to emit 5V)
  • 18650 - 4 3.7V batteries, two 2S battery packs
  • TB6612FNG - 2 motor drive to control motors
  • LM393 - 2 IR encoder to count slots and determine motor speed
  • Chassis & Motors - The 4WD chassis and 130 motors with TT gearbox to roam around the rooms
  • HC-SR04 - 3 Ultrasonic Proximity/Distance Sensor to map the room (90° apart)
  • MPU-6050 - The accelerometer and gyroscope to precisely determine position & orientation
  • QMC5883L - The magnetometer to obtain absolute heading direction
  • Miscellaneous Components - Resistors, Capacitors, Diodes, LEDs, Bread Board, Wires, Buttons, Switches

Investment: ₹3,000 💀🙏

HMI

Three buttons:

  • Primary
  • Secondary
  • Tertiary

The primary and secondary buttons are close to each other, while the tertiary button is grouped separately. It is also smaller.

Two LEDs:

  • General Status LED: Red, Green, Blue
  • Input Status LED: Red

The GSLED has RGB channels in one LED unit, with ability to control brightness of each channel programmatically.

The ISLED has only R channel programmatically configurable. Its G and B channels are physically wired to the primary and secondary buttons.

Input Methods:

  1. Normal Method:
    • Primary Button: Commit.
    • Secondary Button: Cycle forward through a list or increment value, with wrap-around.
  2. Adjustment Method:
    • Primary Button: Move forward in a list or increment value, without wrap-around (clamping).
    • Secondary Button: Move backward in a list or increment value, without wrap-around (clamping).

Input methods are configured by pressing the tertiary button, which toggles between Normal Method (default) and Adjustment Method.

Hue Display:

The current index or value is displayed on GSLED by fixing the saturation and brightness, and adjusting the hue based on the index and total.

R Display:

The current index or value is displayed on ISLED by adjusting the baseline brightness on R channel based on the index and total.

Blink:

ISLED uses blink code to denote gesture.

  • Blink 1: 300ms on, return to baseline.
  • Blink 2: 200ms on 200ms off 200ms on, return to baseline.
  • Blink 3: 150ms on 150ms off 150ms on 150ms off 150ms on, return to baseline.
  • Blink 1-long: 500ms on, return to baseline.

On state: 100% if baseline < 38.197%, else 0%

Off state: 0% if baseline >= 38.197%, else 100%

Gestures:

  • Cycle:
    • Normal Method: Secondary button cycles (wrapping).
    • Adjustment Method: Primary and secondary buttons moves (clamping).
    Holding button repeats (4 steps/s) after long-press (within 400ms). ISLED blink: 1 on step, 2 on wrap-around or clamp.
  • Back: Tertiary button goes back a level. ISLED blink: 3.
  • Commit (Only on Normal Method): Primary button commits. ISLED blink: 1.
  • Root: Tertiary button double-press (within 400ms) discards changes (if any) and goes to Home menu, page 0. ISLED blink: 3.
  • Toggle Input Method: Tertiary button long-press (within 400ms) toggles input method. ISLED blink: 1-long.

Navigation:

  • Home: List of status pages.
    • Cycle: Cycle through pages.
    • Back: Go to Page 0.
    • Back on Page 0: Pause & Resume whole system.
    • Commit: Go to Action Selection menu.
    ISLED uses R Display.
    Page 0 is root.
  • Action Selection: List of action pages.
    • Cycle: Cycle through pages.
    • Back: Go to Home menu.
    • Commit: Go to either Value Mode menu or Event Mode menu.
    GSLED uses Hue Display.
  • Value Mode: Input value in range.
    • Cycle: Cycle through value in range.
    • Back: Revert changes and go to Action Selection menu.
    • Commit: Save changes and go to either Reports menu or Action Selection menu.
    ISLED uses 50% baseline.
    GSLED uses Hue Display.
  • Event Mode: Action performance.
    • Cycle: Does nothing.
    • Back: Does nothing.
    • Commit: Save changes and go to either Reports menu or Action Selection menu.
    Busy wait phase.
    ISLED uses 50% baseline.
    GSLED uses Hue Display as loading indicator by default.
  • Reports: List of action results.
    • Cycle: Cycle through results.
    • Back: Go to either Value Mode menu or Event Mode menu.
    • Commit: Go to Action Selection menu.
    ISLED uses R Display.

Pages:

  • Home:
    1. Battery Status: GSLED:
      • R = 1 - min(bat1, bat2)
      • G = bat1
      • B = bat2
    2. Proximity Status: GSLED:
      • R = Front
      • G = Left
      • B = Right
  • Action:
    1. Motor Trim
